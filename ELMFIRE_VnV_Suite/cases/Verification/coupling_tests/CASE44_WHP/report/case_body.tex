\section{Verification purpose}

This case verifies the response of the intended downscaled Wildland--Urban ELMFIRE (WU--E) model-2 heat
calculation to the design-fire curve, target building-fuel properties,
heat-release-rate (HRR) ellipse adjustment, the radiation cutoff, and multiple simultaneous
sources.  It is designed to expose breakpoint errors, confusion between a
plateau duration and its absolute end time, use of the wrong target-property
path, incorrect heat-area normalization, missing cutoff logic, a failure to
accumulate transient heat, or nonlinear source aggregation.

Nineteen deterministic simulation conditions use one or two stationary WU-E sources.
Nonburnable fire behavior fuel model (FBFM) 93 background and a zero spread-adjustment raster suppress
propagation; spotting, terrain, and weather variation are disabled.  The
intended downscaled formulation is the numerical acceptance reference. The
reviewed configuration interpretation, spread-rate calculation, and level-set
formulation were identical to the specified ELMFIRE source revision; this
identity claim does not extend to all other model components. Differences
between the simulated response and the intended equations below are reported
as deviations.

\textbf{Verification question.} Do all simulation conditions reproduce the complete
time-dependent heat-release rate per unit area (HRRPUA), direct-flame-contact (DFC), radiation, and accumulated-heat
fields within \HeatMapTolerance{} normalized $L_1$ error, while satisfying
the exact parameter scalings, radiation support, source-superposition, and
no-propagation invariants?

\section{Mathematical formulation and numerical implementation}

For elapsed burning time $t$, the implementation reads four values from the
source building-fuel-model row: growth endpoint $t_e$, absolute plateau
endpoint $t_f$, decay endpoint $t_d$, and peak HRRPUA $H$.  It evaluates

\begin{equation}
 \HRRPUA(t)=
 \begin{cases}
   Ht/t_e, & t\le t_e,\\
   H, & t_e<t\le t_f,\\
   H(t-t_d)/(t_f-t_d), & t_f<t\le t_d,\\
   0, & t>t_d.
 \end{cases}
\end{equation}

The fixed wind and geometry determine the UCB ellipse once per source. With
linear characteristic building dimension $L_c=\texttt{BLDG\_AREA}$ in metres,
source area $A_s=L_c^2$, ellipse major and minor radii $B$ and $A_e$, and
$c=\texttt{HRR\_ELLIPSE\_ADJ}$, the intended spatial normalization is

\begin{equation}
 C_h=\frac{A_s}{\pi(cB)(cA_e)},\qquad c_{default}=1.
\end{equation}

For target cell $j$, define
$\beta_{ssd}=\min[1,(s_{sd}+L_c)/\Delta x]$ and select
$K_\theta=B+E$, $B-E$, or $2A_e$ for downwind, upwind, or sidewind sectors.
The clipped DFC coverage is
$f_d=\operatorname{clip}[(K_\theta+\Delta x/2-r\beta_{ssd})/\Delta x,0,1]$.
Radiation uses $r_{eff}=r\beta_{ssd}c$, physical $HAZ=100$ m, and the
complementary factor $(1-f_d)$. Spatial nonburnable fraction $n_j$ takes
precedence when supplied; the building-model/default value is the fallback.
The table supplies absorptivity $\alpha_j$. Each source $s$ contributes

\begin{align}
 q''_{\mathrm{DFC},s,j} &= g_f\eta(W)0.65(1-n_j)f_{d,s,j}\,\dot q''_{\mathrm{HRR},s}(t)C_h,\\
 q''_{\mathrm{rad},s,j} &= g_f\eta(W)\frac{0.35(1-n_j)\alpha_j f_{r,s,j}
                 \dot q''_{\mathrm{HRR},s}(t)A_s}{4\pi r_{\mathrm{eff},s,j}^2},\\
 \eta(W)&=\frac{3.25}{1+\exp[-0.05(W-75)]}+0.5,\qquad
 g_f=\min[(\Delta x/L_c)^2,1].
\end{align}

Radiation overlap is exactly zero outside the physical heat-affecting zone,
with half-cell clipping. Transient maps sum all burning
sources.  Total received heat is updated every one-second solver step as

\begin{equation}
 Q^{\mathrm{total}}_j \mathrel{+}=q''_j(t)\,\Delta t\,\Delta x^2.
\end{equation}

The independent case-specific Python reference calculation implements these equations directly;
it imports no ELMFIRE code and has no execution source-tree dependency. The
pinned source currently omits $\eta$, uses 0.3 rather than 0.35 radiation,
omits the 0.65 DFC factor and grid corrections, and uses cell area in $C_h$.

\section{Derivation of expected behavior}

The four source curves deliberately sample every breakpoint.  The base curve
uses $(t_e,t_f,t_d,H)=(4,8,12,100)$ in SI units; the peak simulation condition doubles
$H$, the short curve uses $(2,4,6,100)$, and the long-plateau curve uses
$(4,10,14,100)$.  Because every heat term is linear in HRRPUA, doubling $H$
must double the HRR and both heat-flux maps at every dump.

At fixed geometry, DFC scales with spatial $1-n_j$, while radiation scales with
$(1-n_j)\alpha_j$. The spatial input therefore predicts exact response ratios
for $n_j\in\{0,0.2,0.5,1\}$ and
$\alpha_j\in\{0,0.4,0.8,1\}$.  DFC must not change in the absorptivity sweep.
At fixed $B$ and $A_e$, both heat fields scale as $c^{-2}$ for
$c\in\{0.25,0.5,0.75,1\}$.

The sum from a left and a right source must equal the two-source result cell
by cell and dump by dump.  Likewise, the final accumulated rasters must equal
the sum of every one-second transient raster times $\Delta t\Delta x^2$.
Finally, two simulation conditions change the spatial nonburnable-fraction raster from zero
to one while retaining the same building-fuel-model table. The fully
nonburnable target must receive zero DFC and radiation; equality would expose
the current source's table-only behavior.

\section{Verification metrics and acceptance criteria}

For nonzero reference array $R$ and output array $E$, the principal metric is

\begin{equation}
 \nLone=\frac{\sum |E-R|}{\sum |R|}.
\end{equation}

The sums cover all 16 scheduled dump times and every raster cell.  A zero-reference
array uses absolute $L_1$ error, so a supposedly suppressed component cannot
pass through a zero denominator.  Nodata, non-finite values, unexpected
shapes, duplicate result fields, and output times other than exactly 1 through
16 seconds are rejected.  The prescribed HRR curves include $t=0$, but
ELMFIRE's first scheduled output occurs after one scheduled output interval.
A confirmed successful completion must have matching SHA-256 identities for
the simulation settings, spatial inputs, both fuel-property tables, reference
and analysis methods, ELMFIRE program, simulation record, and all results.
Output labels alone are not sufficient evidence. The relationship between the
identified model program and the stated source revision must be established
separately.

\section{Technical interpretation}

The required transient stacks are unavailable because the solver stops when
this one- or two-source setup has too few tagged propagation cells. The dormant
ignition controls the separate PHI-stall test, not this low-node stopping rule.
An overrun final dump does not contain the missing rise, plateau, and decay
history, so the current decision remains NOT EVALUABLE.

Once complete histories exist, the comparisons separate distinct causes:
HRR errors indicate curve timing or source-state problems; correct HRR with
incorrect heat maps indicates transfer coefficients, support, or normalization;
a transient-to-total mismatch indicates accumulation or dump timing. The
spatial-nonburnable and source-superposition controls test their respective
input and aggregation paths without substituting planned values for output.

\section{Scope and limitations}

This case verifies deterministic source HRR and heat-transfer mechanics for a
fixed model-2 ellipse.  It does not verify physical calibration, flame-shape
regressions across wind and geometry (CASE43), ignition thresholds, rate of spread (ROS),
wildland--urban transitions, embers, fuel consumption, or convergence.  Its
intended spatial-property interpretation is tested against the pinned source
revision. The reference calculation is evaluated independently of the
ELMFIRE simulation.
